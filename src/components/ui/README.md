# UI 부품과 규칙

> 화면은 이 폴더의 부품으로 만든다. 버튼·입력칸·모달·카드를 화면에서 직접 그리지 않는다.
> 모든 부품은 개발 서버의 `/dev/ui`에서 한눈에 본다.

## 원칙

> 목표는 Nous Research · Instagram · Vercel. **흑백, 글자가 이끄는 화면, 색은 최소, 아이콘은 한 벌.** (2026-11-01 새 체계)

- **흑백이 기본, 라이트·다크 둘 다.** 주 버튼은 글자색 바탕(`primary`: 라이트=검정, 다크=흰색). 강조는 색이 아니라 밝기와 크기로.
- **색은 시그널(볼트) 하나.** 칠할 때는 `bg-signal`, 글자·아이콘은 `text-signal-fg`(라이트에서 읽히게 어둡다). 승리 왕관, 진행 중 점, 안 읽음 숫자, 챔피언, 형광펜(`.hl`).
- **빨강(`danger`)은 위험에만.** 삭제·신고·오류. 패배는 빨강이 아니라 흐린 글자·빈 테두리로.
- **한 화면에 주 행동은 하나.** 목록 안에서 반복되는 행동(카드의 '신청')은 테두리 버튼(`tonal`).
- **상자 규칙은 하나.** 화면 안의 상자(카드·목록·숫자 칸·빈 화면 아이콘)는 바탕색만 칠하고 테두리를 쓰지 않는다. 테두리는 ① 입력칸 ② 테두리 버튼·칩 ③ 떠 있는 층(확인 창·띠·토스트)에만. 상자 안을 나눌 때만 구분선(`divide-line`).
- **아이콘은 `UiIcon` 하나.** Lucide 선 아이콘(굵기 1.75). 종목 그림(`CategoryIcon`)도 글자색을 따른다. 새 아이콘은 `UiIcon.vue`의 표에 이름을 더한다.
- **서체.** 라틴·숫자 Geist, 한글 Pretendard. 숫자는 고정폭 대신 표 숫자(`tabular-nums`)로 자리만 맞춘다. `t-mono`·`font-mono`도 Geist다 (빗금 0·터미널 느낌을 뺐다, 11/3).
- **모서리.** 칩·배지 8px, 버튼·입력칸·카드 12px, 시트 16px, 원.
- **누르는 곳은 44px 이상.** `UiButton` md 이상, `UiIconButton`을 쓰면 저절로 지켜진다.

## 토큰 (`tailwind.config.cjs`)

| 이름 | 쓰는 곳 |
|---|---|
| `bg-canvas` | 화면 바탕 |
| `bg-surface` | 카드·시트 |
| `bg-surface-2` / `surface-3` | 입력칸·카드 안의 칸 / 보조 버튼·눌린 상태 |
| `border-line` / `line-strong` | 구분선 / 테두리 버튼·칩 |
| `text-fg` / `fg-muted` / `fg-subtle` | 본문 / 보조 / 시간·개수 |
| `primary` | 주 행동 (흰색). `-on`은 그 위 글자(검은색) |
| `signal` | 유일한 색 (볼트). 승리·진행 중·안 읽음·챔피언 |
| `danger` | 삭제·신고·오류 |
| (라이트·다크) | 값은 `src/assets/tailwind.css`의 `--c-*` 변수. 기본은 폰 설정, 설정 > 화면에서 바꾼다 |
| `z-header` < `z-nav` < `z-sheet` < `z-dialog` < `z-toast` | 겹치는 순서. 숫자(`z-[9999]`)를 쓰지 않는다 |

**제목은 두 단계뿐**: 화면마다 하나인 화면 제목(`t-title`), 그 안의 묶음 제목(`t-heading`, `UiSection`이 쓴다). 고정폭(`t-mono`, `font-mono`)에는 숫자·영문만 넣고 한글은 넣지 않는다.

글자는 크기·굵기를 직접 고르지 않고 역할 클래스를 쓴다: `t-display` `t-title` `t-heading` `t-body` `t-label` `t-caption` `t-micro` `t-mono`. 굵기는 semibold까지만 쓴다(`font-bold`도 620으로 가볍게 잡혀 있다).

## 부품

| 부품 | 언제 |
|---|---|
| `UiTopBar` | 모든 화면 맨 위. 탭 화면은 `title`만, 들어간 화면은 `back` |
| `UiButton` | 모든 버튼. `variant`(primary·secondary·ghost·danger), `size`(sm·md·lg), `block`, `loading`, `icon`, `to` |
| `UiIconButton` | 아이콘만 있는 버튼. `label`은 필수 |
| `UiInput` / `UiSelect` / `UiField` | 입력. `label`, `hint`, `error`, `optional` |
| `UiCard` | 한 덩어리 정보. 누르면 들어가는 카드는 `to`·`interactive` |
| `UiList` + `UiListItem` | 설정·알림·사람 목록 |
| `UiSection` | 화면 안의 묶음 (제목 + 오른쪽 행동) |
| `UiChip` / `UiBadge` / `UiTabs` | 고르기 / 상태 / 보기 바꾸기 |
| `UiAvatar` | 프로필 사진. 없으면 이름마다 정해지는 차분한 그라데이션 + 첫 글자 |
| `BrandFace` / `BrandMark` | 매치 얼굴(셔틀콕 머리·축구공 눈·농구공 솔기·볼트 입) / 얼굴 + `match` 글자. 표정 `mood`: smile·neutral·wow. 당겨서 새로고침, 404, 이긴 순간, 빈 화면(`UiEmptyState face`)에 쓴다 |
| `UiRollNumber` | 결과 점수·승률처럼 '나온 순간'이 중요한 숫자. 점수판처럼 굴러 올라온다 |
| `UiIcon` | 모든 아이콘. `name="plus"` (예전 `fas fa-plus`도 받는다), 켜진 하트·별은 `filled` |
| `UiEmptyState` | 비었을 때: 무엇이 없는지 + 다음 행동 |
| `UiSkeleton` / `UiListSkeleton` | 불러오는 동안 실제 모양 그대로 자리 표시 (빛이 지나간다) |
| `UiSpinner` | 버튼·작은 곳의 기다림. 화면 전체를 스피너로 막지 않는다 |
| `UiSheet` | 목록·상세·고르기처럼 내용이 있는 것. 아래에서 올라온다 |
| `confirmDialog()` (`UiActionSheet`) | 사용자가 직접 시작한 일을 한 번 더 확인 (삭제·나가기·로그아웃). 아래에서 올라오고 취소는 따로. `await confirmDialog({...})` |
| `UiDialog` | 가운데 알림. **예상 못 한 문제를 알릴 때만** (보낼 수 없어요). 확인·할 일에는 쓰지 않는다 |

시트·다이얼로그는 뒤로가기·바깥 누르기·Esc로 닫히고, 열린 동안 뒤 화면이 스크롤되지 않는다(`useOverlay`).

## 기다림

- **화면을 불러올 때는 스켈레톤.** 실제 내용과 같은 모양·크기로. "불러오는 중..." 글자와 큰 스피너를 쓰지 않는다
- **버튼은 `loading`.** 글자 자리를 지킨 채 스피너가 올라간다 (폭이 흔들리지 않게)
- **내용이 들어오면 `ui-appear`** 로 살짝 올라오며 나타난다
- 화면 이동이 150ms를 넘으면 맨 위에 얇은 진행 막대가 저절로 뜬다 (`RouteProgress`)
- 움직임 줄이기 설정이면 빛·올라오기를 멈춘다

## 문구

- **말투는 "~해요"로 통일.** "~합니다", "~하십시오"를 쓰지 않는다.
- **버튼은 동사로, 결과를 말한다.** "확인" 대신 "삭제", "저장", "신청".
- **빈 값은 숨긴다.** "연령 -"처럼 대시를 보여주지 않는다.
- **비었을 때는 다음 행동을 준다.** "기록이 없습니다"로 끝내지 않고 버튼을 둔다.
- **오류는 무엇을 하면 되는지 말한다.** "실패했습니다" 대신 "잠시 뒤 다시 해 주세요", "아이디를 적어 주세요".
- **"해 주세요"·"해 보세요"는 띄어 쓴다.** (도와주세요·찾아보세요처럼 한 낱말인 것만 붙인다. 남겨 보세요, 보내 보세요, 바꿔 보거나)
- **알림 제목·버튼·입력칸 안내 끝에는 마침표·말줄임표를 찍지 않는다.** ('댓글 달기', '경기가 끝났어요'). 두 문장이면 사이에만 찍는다
- **잘리는 줄은 중요한 것부터.** 한 줄에 때·장소를 함께 쓰면 때를 앞에 둔다 (장소가 잘리게)
- **쉬운 말.** 촬영 → 찍기, 게시 → 올리기, 조치 → 처리, 입력 → 적기, 관전 → 구경.
- **버튼은 짧은 동사구.** 문장(“점수가 달라요, 고쳐서 보낼게요”)이나 괄호 설명(“그만두기 (지게 돼요)”)을 넣지 않는다. 설명은 버튼 위아래 글이나 확인 시트로.
- **설명 글은 한 문장에 한 가지.** 주어를 앞에, 괄호·가운뎃점 나열을 줄인다. 오르는 때와 내리는 때처럼 갈래가 있으면 문장을 나눈다.
- **자세한 계산·근거는 숨긴다.** 화면에는 숫자와 한 줄, 나머지는 ⓘ를 눌러 시트로 (점진적 공개).

### 브랜드 (11/3, `docs/essence.md`를 따른다)

- **목소리는 '줄 말고 판'.** 지면 낙오가 아니라 다음 판, 1등은 혼자 될 수 없다. 이긴 쪽만 축하하고 진 쪽을 회색으로 깎지 않는다 (`utils/verdict.ts`)
- **브랜드는 입구에만 두지 않는다.** '찾기' 맨 위 하루 한 줄(`utils/brandLines.ts`, 본문 크기로 조용히, 핵심 낱말만 진하게 볼트 밑줄. 제목처럼 크게 쓰거나 형광펜 상자로 칠하지 않는다), 빈 화면의 얼굴, 진 순간의 담담한 얼굴
- **볼트는 셋에만.** 형광펜(이긴 이름·핵심 낱말), 승리 막대, **내 차례**(`UiButton variant="signal"`: 결과 확인·신청 승인, 하단 '내 경기' 숫자). 한 화면에 볼트 버튼은 하나
- **빈 화면은 얼굴.** `UiEmptyState`는 다음 할 일(버튼)이 있으면 웃는 얼굴, 없으면 담담한 얼굴. 오류(못 불러옴·끊김)만 아이콘
- **숫자는 Geist 표 숫자.** 고정폭·빗금 0을 쓰지 않는다. 큰 점수는 semibold
- **상자 안에 상자를 두지 않는다.** 카드 안의 점수·표는 여백과 줄로
- **위쪽 버튼은 두 가지만.** 채운 주 행동 하나 + 같은 모양의 갈 곳
- **손맛은 `feel()` 하나로.** 일이 일어난 순간의 이름만 부른다(`tap`·`select`·`score`·`success`·`win`·`lose`·`alert`·`error`), 진동·효과음은 `utils/feel`이 함께 낸다. 버튼마다 울리지 않는다: 고르기·점수·확정·승부처럼 '무언가 일어난' 순간에만. 진 순간은 오류 진동이 아니라 가벼운 진동과 내려가는 소리. 설정 > 효과음·진동으로 끈다
- **움직임은 짧고 한 번.** 눌림(살짝 작아짐), `feel-pop`(바뀐 숫자·고른 탭), `feel-rise`(결과가 차례로), `win-spark`(이긴 얼굴). 모두 움직임 줄이기에서 멈춘다
- **앱 게임은 칸으로.** 게임마다 다른 그림(`utils/appGameIcon.ts`), 모두 같은 말은 빼고 다를 때만

### 용어 (11/3 정리)

| 쓴다 | 쓰지 않는다 | 뜻 |
|---|---|---|
| 경기 | 대결 | 규칙 하나로 겨루는 한 판. 버튼에서만 "한 판 하기" |
| 실력 점수 | 레이팅 | 규칙마다 매기는 점수. 1500에서 시작 |
| 연습 점수 | 연습 레이팅 | 봇(연습 상대)과 한 판으로 바뀌는 점수 |
| 신뢰 온도 | 매치 온도 | 처음 만나도 괜찮은 사람인지. 36.5도에서 시작 |
| 결과 다툼 | 결과 이견 | 결과가 끝내 맞지 않은 경기 |
| 모집 중인 경기 | 열린 경기 | 신청을 받는 경기 |
| 앱 게임 | 앱 안 게임 | 만나지 않고 폰으로 하는 게임 |
| 소식 | 피드 | 끝난 경기와 지금 하는 경기가 올라오는 탭 |
| 찾기 / 내 경기 | 경기 / 내 경기 | 하단 탭. 글자 하나 차이로 헷갈려 나눴다 |

챔피언·포인트·규칙·신청(모집 중인 경기에 끼기)·도전(한 사람에게 경기를 걸기)은 그대로 쓴다.
